# 見本1：形式がバラバラな売上Excelの自動集計

※本見本は架空のデータで作成しています。実在の企業・店舗とは関係ありません。

## 想定した困りごと

3店舗のカフェで、店舗ごとに売上の記録方法が違うため、本部の担当者が毎月、手作業で転記・修正してから集計している。

| 店舗 | 記録のクセ |
|---|---|
| 新宿店 | 比較的きれいだが、商品名の前に空白が混じる |
| 吉祥寺店 | 表の上にタイトル行、日付が「7月1日」、金額が「1,350円」という文字、全角数字、空行 |
| 立川店 | 月ごとに別シート、英語の列見出し、半角カナの商品名、売上列がない、末尾に合計行 |

## 作ったもの

`input/` にファイルを置いて `python monthly_report.py` を実行するだけで、次を自動で行います。

1. 各ファイル・各シートの列見出しを自動で探し、別名の列（「品名」「Item」など）をそろえる
2. 全角・半角のゆれ、空白、「円」やカンマ、日付の書き方を統一する
3. 空行や合計行を取り除き、売上列がなければ「数量×単価」で計算する
4. 月次レポート（Excel）を出力する

## 出力されるレポート

| シート | 内容 |
|---|---|
| サマリー | 店舗×月、商品×月の集計表とグラフ。集計はExcelの数式なので、明細を直せば自動で再計算される |
| 明細 | 整形後の全データ（1,113件） |
| 処理ログ | どのファイルから何件読み込み、何を何件除外したか |

## 工夫した点

- **検算の仕組み**：明細の総額とサマリーの合計が一致するかを自動で確認
- **処理ログ**：自動処理を「ブラックボックス」にせず、何をどう直したかを後から確認できる
- **設定の分離**：列の別名や店舗名は冒頭の設定部分にまとめてあり、別の会社のデータにも少しの書き換えで対応できる

## 効果（想定）

| | 作業前 | 作業後 |
|---|---|---|
| 毎月の集計作業 | 手作業で転記・修正して数時間 | 実行して数秒 |
| 転記ミス | 起こり得る | 検算で確認できる |

## 使い方

```
pip install pandas openpyxl
python generate_sample_data.py   # 架空データの作成（見本用）
python monthly_report.py         # 月次レポートの作成
```
